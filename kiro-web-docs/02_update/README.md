## 🔖 Kiro Web の更新の識別

**Kiro Web にはバージョン番号がありません。** 更新は**日付とスラッグ**で識別します。

| 項目 | 内容 |
|------|------|
| 正準キー | **日付（ISO `YYYY-MM-DD`）＋スラッグ** |
| エントリ数 | **7** |

| 最新のエントリ | 2026-07-01 |

> ⚠️ **公式 changelog に載らない公式ドキュメントの更新があります。** 2026-08-01 時点で、最新エントリ（2026-07-01）より新しい docs の更新が4件ありました。本サイトでは各ページに**出典日**を記載しています。

## 📌 記述の粒度

エントリの構造は2種類あります。

| 粒度 | 構造 | 件数 | 本サイトの書き方 |
|------|------|------|----------------|
| **W-L2** | 見出し節または導入文のみの機能紹介型 | 5 | 見出しと本文を全量記載 |
| **W-L3** | `Improvements`・`Fixes` の折りたたみ節を持つ保守型 | 2 | 導入文＋**折りたたみ内の全項目**（計21項目）を記載 |

折りたたみ節の項目は公式サイト上では初期状態で隠れていますが、**省略せずに全量を記載**しています。
