## 🔖 Kiro Web の更新の識別

**Kiro Web にはバージョン番号がありません。** 更新は**日付とスラッグ**で識別します。

| 項目 | 内容 |
|------|------|
| 正準キー | **日付（ISO `YYYY-MM-DD`）＋スラッグ** |
| エントリ数 | **22** |
| 最古のエントリ | 2025-12-02 |
| 最新のエントリ | 2026-10-12 |

> ⚠️ **公式 changelog に載らない公式ドキュメントの更新があります。** snapshot（2026-10-25）では、最新エントリ（2026-10-12）より後に更新された Web docs が 11 件ありました。changelog に現れない docs の更新も監視対象です。本サイトでは各ページに**出典日**を記載しています。

---

## 📌 記述の粒度

エントリの構造は2種類あります。

| 粒度 | 構造 | 件数 | 本サイトの書き方 |
|------|------|------|----------------|
| **W-L2** | 見出し節または導入文のみの機能紹介型 | 18 | 見出しと本文を全量記載 |
| **W-L3** | `Improvements`・`Fixes` の折りたたみ節を持つ保守型 | 4 | 導入文＋**折りたたみ内の全項目**（計57項目）を記載 |

折りたたみ節の項目は公式サイト上では初期状態で隠れていますが、**省略せずに全量を記載**しています。
